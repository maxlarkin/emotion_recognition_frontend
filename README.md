# EmoSense — веб-интерфейс

Веб-интерфейс системы распознавания эмоций по лицу и голосу в реальном времени. Он рассчитан на работу в зале обслуживания: показывает камеры, отмечает негативные эпизоды у клиентов и ведёт журнал инцидентов.

Что есть в интерфейсе:

- сетка RTSP-камер с рамками лиц, решением по каждому лицу и задержкой анализа;
- экран камеры: баннер инцидента, посетители в кадре, журнал по интервалам, параметры обработки;
- сеанс веб-камеры и микрофона браузера с задержкой p50/p95;
- анализ записей: очередь загрузки, плеер с рамками, график эмоций, эпизоды;
- журнал событий с фильтрами, подтверждением инцидентов и экспортом;
- список сеансов с экспортом в CSV и JSON;
- настройки событий, камер и журнала, состояние системы.

Сервер сейчас не нужен: все запросы обрабатывает заглушка в браузере, она показывает демо-данные. Подробности в [STUBS.md](STUBS.md).

## Быстрый старт

Нужен Node.js 22.

```bash
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Браузер разрешает доступ к камере и микрофону на `localhost` без HTTPS.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер разработки Vite с горячей перезагрузкой. |
| `npm run build` | Проверка типов (`tsc --noEmit`) и сборка в `dist/`. |
| `npm run preview` | Раздача собранного `dist/`. |
| `npm test` | Все тесты Vitest один раз. |

Docker-образ (сборка в Node, раздача через nginx):

```bash
docker build -t emosense-frontend .
docker run --rm -p 8080:80 emosense-frontend
```

## Стек

- React 19 и react-router 8;
- TypeScript 7 в строгом режиме;
- Vite 8;
- Vitest 5, Testing Library и jsdom для тестов;
- шрифты IBM Plex из пакетов `@fontsource`, без загрузки из сети.

## Структура

```
src/
  App.tsx           маршруты
  main.tsx          точка входа, подключение стилей
  api/              единственная точка доступа к данным
    index.ts          объект api: выбор между заглушкой и клиентами сервера
    types.ts          типы данных API
    stub/             заглушка: сервер в памяти, симуляция, сокет /ws/live
    real.ts           REST-клиент сервера
    streamsSocket.ts  клиент /ws/streams
  shell/            шапка, меню, колокольчик, баннер состояния сервера, контекст оболочки
  state/            AppData: общее состояние потоков, кадров, инцидентов, нагрузки
  streams/          сетка потоков, левая колонка, экран потока, диалог добавления
  live/             веб-камера: захват кадров и звука, протокол, рамки, задержка
  history/          журнал событий и экран сеансов
  sessions/         таблица сеансов
  settings/         настройки: события, камеры, журнал, система
  analyze/          анализ записей: очередь, результат, эпизоды
  ui/               общие элементы интерфейса, форматирование, иконки
  styles/           токены, базовые стили, стили экранов
  build/            тест защиты от внешних адресов в бандле
docs/               документация
Dockerfile, nginx.conf   образ с nginx
```

## Главные правила

- Весь текст интерфейса на русском.
- Экраны получают данные только через `src/api` (объект `api`) и `src/state/appData.ts`.
- Приложение работает без интернета: никаких CDN, удалённых шрифтов и внешних адресов в бандле. Сборка проверяет это сама.
